# AI Lab results

Experiment results generated by the Blankdiss AI Lab.

Each experiment gets its own directory:

    data/ai_lab/results/<experiment-id>/

Typical output:

    results.json
    report.md

The results are committed back to the repository by GitHub Actions.

## Research state

The AI Lab can create a read-only research-state snapshot.

The snapshot describes:

- current research specifications
- locked research specifications
- current research questions
- previous AI Lab experiments
- previous research-engine runs

The research-state snapshot does not:

- modify research specifications
- modify locked parameters
- select test parameters
- optimize against test data
- declare a hypothesis confirmed

The purpose is to provide the reasoning layer with an explicit,
auditable description of the current research state.
